## Как измерено

- коммиты, файлы и строки — `git rev-list --count`, `git ls-files`, подсчёт строк
  по отслеживаемым `*.ts`, `*.vue`, `*.scss`, `*.mjs`, `*.css` (без `pnpm-lock.yaml`
  и сгенерированных файлов);
- тесты — `pnpm test` / `pnpm verify`;
- Lighthouse — `pnpm audit:site` по локальной статической сборке
  (`http://127.0.0.1:4319/`), пороги из `scripts/lighthouse.ts`;
- артефакты и размер статики — `pnpm build:all` и размер файлов
  `.output/public`;
- живой сайт — HTTP `HEAD` на `https://mikeiv.github.io/resume/...`;
- сухой прогон hh-autopilot — `pnpm hh:collect`, `pnpm hh:score`,
  `pnpm hh:letters`, `pnpm hh:apply --dry-run` на локальной базе.

## Ограничения

- Lighthouse снят с локальной SSG-сборки, а не с GitHub Pages; хостинг может
  добавить сетевые метрики (TTFB, кеш), но категории и пороги проверяются локально.
- Цифры hh-autopilot по вакансиям — снимок локальной базы (в git не входит), а не
  свойство репозитория.
