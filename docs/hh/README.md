## Что решено 2026-10-31

- Опыт: три основных места блоками (`experience`), вся остальная история — строкой
  «Разные компании» в раннем опыте. Так PDF остаётся в двух страницах.
- Комментарий о смене компаний — только факты из выписки: даты, компании, должности,
  без объяснения причин.
- Образование записано полным именем вуза.
- PDF печатается с масштабом 0.95 (`scripts/emit-pdf.ts`): иначе блок опыта переезжает
  на третью страницу.
